# js-object-clock-2026

基于 [unktir/js-object-clock](https://github.com/unktir/js-object-clock) 重构，展示常用时间信息。页面字号随屏幕短边调整，主题面板布局适配不同视口；主题按钮和面板根据浏览器语言显示简体中文或英文，时钟字段保持英文。

主题选择包含 VS Code 内置的浅色、现代浅色、2026 浅色、深色、现代深色和 2026 深色，配色值以 [VS Code 内置主题定义](https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults/themes) 及其默认颜色为准。默认跟随系统外观切换 2026 浅色或深色，也可手动选择并记住偏好。
